# 二维 SIMP 拓扑优化教学项目

## Windows 启动与验证

在包含 `app.py` 的项目目录打开 PowerShell。首次使用时创建环境并安装依赖，已有 `.venv` 时直接使用其中的 Python。

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

打开 [Stage 1](http://127.0.0.1:8501/)。顶部导航可进入 [Stage 2](http://127.0.0.1:8501/Stage_2) 和 [阵列力学验证](http://127.0.0.1:8501/Array_Validation)。已有虚拟环境也需用上述安装命令补装 Plotly。更新运行中的 Python 模块后，可重启 Streamlit 服务加载新版本。

```powershell
.\.venv\Scripts\python.exe -B test_optimizer.py
.\.venv\Scripts\python.exe -B test_homogenization.py
.\.venv\Scripts\python.exe -B test_projection_and_array.py
```

## Stage 1 · 二维结构最小柔度

- 设计域支持矩形、黑白 PNG 和点击绘制的多边形。PNG 的白色像素为可设计域，黑色和全透明像素为空区，按最近邻缩放到网格。多边形按单元中心栅格化。绘制后点击「应用多边形」，即可预览求解域。
- 在「绘制区域」模式编辑多边形。在「添加载荷」中点击一个网格节点，填写 Fx、Fy 后点击添加。在「添加约束」中可以点击单个节点，也可打开「框选节点」拖选一组，指定 Ux、Uy 或两个方向。「编辑删除」中选一条记录，点击图上的目标节点或修改整数坐标，即可移动，分量与约束方向也可修改。保存或删除后点击「开始拓扑优化」重新求解。
- 只需换位置时，选择「添加载荷 → 移动已有载荷」，选中载荷后在图上点选目标或输入整数坐标，再点击「移动所选载荷」。已保存载荷列表会显示新坐标。可应用悬臂梁、简支梁或空白预设。坐标原点在左下角，节点编号从 0 开始，`n=j*(nx+1)+i`，自由度为 `2*n` 和 `2*n+1`。水平向右、竖直向上为正。同节点载荷累加，约束方向取并集。灰粉色节点未接触设计单元，选中会提示，坐标不迁移。
- 可设置弹性模量、泊松比、网格、体积分数上限、SIMP 惩罚指数和滤波半径。程序检查载荷和约束节点是否接触设计域、载荷方向是否受约束、以及约束能否去除平移和转动刚体模态。
- 沿用平面应力 Q4 单元、稀疏方程求解、密度滤波和 OC 更新。第 0 步是初始设计，第 1 步起为每次 OC 更新后的设计。每一步均重新求解有限元并保存物理密度、柔度和体积分数，结果页可滑动查看任意步。
- 默认悬臂梁为 60×20 单元、40% 材料、SIMP 指数 3、滤波半径 2.5。完整结果 ZIP 包含 `iteration_history.csv`、`optimized_density.png`、`density_history.npy`、`design_mask.npy` 和 `settings.json`。CSV 与 NPY 的第 0 行对应初始设计。
- 对应代码为 `app.py`、`boundary_editor.py` 和 `optimizer.py`。图上节点事件由 [Streamlit Plotly on_select](https://docs.streamlit.io/develop/api-reference/charts/st.plotly_chart) 处理。测试覆盖坐标与编号、节点有效性、载荷叠加、自由度变更、奇异矩阵和悬臂梁。默认柔度由 1841.457051 降至 337.614101。

## Stage 2 · 周期单胞等效体积模量最大化

对 Q4 单胞采用位移分解 `u(x) = ε̄x + w(x)`。以节点坐标对单胞尺寸取模，将两对边和四个角的波动位移自由度精确合并。固定一组代表节点的两个波动分量以去除整体平移。总位移的对边跳量由宏观应变与周期向量确定。

三个独立工况使用平面应力 Voigt 顺序 `[εxx, εyy, γxy]`，其中 `γxy = 2εxy`。对每个设计一次分解周期刚度矩阵并求解三个右端项。用不同工况的总位移计算互应变能，按单胞面积归一化：

```text
Cᴴ[a,b] = Σₑ (uₑᵃ)ᵀ Kₑ(ρₑ) uₑᵇ / (nx × ny)
Kᴴ = (Cᴴ[1,1] + Cᴴ[2,2] + 2 Cᴴ[1,2]) / 4
```

第二式采用从 1 开始的 Voigt 下标，定义等双轴应变下的二维体积模量。单胞允许各向异性，页面提供完整刚度矩阵。均匀实心材料的解析值为 `E/[2(1−ν)]`。

- 选择 32、64、96 或自定义横纵分辨率。滤波半径按 `max(1.1, 基准半径 × min(nx,ny)/32)` 换算成单元数。默认基准半径 2 对应 2、4、6 个单元，保持相对单胞短边的尺度。FFT 卷积实现与原稀疏矩阵相同的周期锥形滤波。
- 设计变量经周期滤波得到 `z`，再经 Heaviside 投影 `ρ=[tanh(βη)+tanh(β(z−η))]/[tanh(βη)+tanh(β(1−η))]`。OC 使用体积模量与物理体积分数的链式导数，并以实际投影体积二分搜索。β 从 1 逐级加倍，每次切换后恢复目标物理体积分数并重新求解。只在达到最终 β 且连续三步满足设计变化、相对目标变化和体积偏差容差后确认收敛。曲线记录真实计算结果，β 切换处可能出现跳变。
- X/Y 镜像与四重旋转通过对称等价组施加。四重旋转需正方形单胞。阈值连通性用四邻域与周期接缝计算，并检查各分量是否有绕过整个单胞的 X/Y 路径。阈值、连通性和对称约束的选择可在页面查看。
- 原始设计、物理密度和二值预览分别显示。3×3/5×5 用同一数组直接平铺。结果 ZIP 包含两种拼接的物理密度和二值 PNG、原始设计与物理密度 NPY、刚度与历程 CSV、设置和可选灵敏度 CSV。等效性能对应投影物理密度。
- 对应代码为 `pages/Stage_2.py`、`projected_optimization.py`、`cell_geometry.py` 和 `homogenization.py`。原均匀材料、层合材料、位移跳量基准仍通过。带投影与旋转约束的中心差分基准中，体积模量和体积分数的最大相对误差约为 4.14×10⁻¹⁰ 和 3.63×10⁻¹⁰。默认 32×32、50% 算例在第 88 步满足收敛条件，体积模量从 0.060496 提高至 0.176380。

## 阵列力学验证

在 Stage 2 求解后选择「将物理密度送入阵列力学验证」，或通过顶部导航打开该页。选择 3×3 或 5×5，像 Stage 1 一样设置节点载荷与零位移约束，点击「计算有限阵列」。内部拼接接缝共用节点，外边界是用户指定的有限结构边界。节点有效范围由非零物理密度单元确定。页面显示位移幅值、柔度和反力，ZIP 提供密度、位移、残差力数组、边界表格及设置。

对应代码为 `pages/Array_Validation.py`，使用 `optimizer.py` 的有限 Q4 组装与位移求解。均匀拉伸基准的解析柔度为 0.50625，节点位移及反力平衡均通过核对。大分辨率配合 5×5 会增加节点数和稀疏分解的内存用量。

## 结果约定

两阶段均采用单位厚度、单位边长的 Q4 单元。改变横纵单元数也会改变计算区域的几何宽高。NPY 数组的第一行对应模型底边，PNG 的第一行对应模型顶边，白色表示密度 1。材料采用 SIMP 灰度插值，空区保留相对刚度 `10⁻⁶`。Stage 1 的体积分数按可设计单元计算，Stage 2 按整个单胞计算。裁剪设计域的承载路径、灰度阈值化后的有效性能以及正式工程用途需要另行验证。
